# MaklerTour Marker Kit v1 storage

Положите официальные AprilTag PNG в директорию:

`web/storage/marker_kits/maklertour_kit_v1/source/tag36h11/`

Ожидаемые имена:
- `tag36_11_00001.png` ... `tag36_11_00030.png`

Допустимые fallback-имена:
- `tag36h11_00001.png` ... `tag36h11_00030.png`

Важно:
- нельзя использовать fake markers;
- нельзя заменять AprilTag на QR-коды.

После добавления PNG откройте:
- `/markers.php` — обзор комплекта;
- `/markers.php?print=all` — печать всего комплекта;
- `/markers.php?print=1..30` — печать одной метки.
