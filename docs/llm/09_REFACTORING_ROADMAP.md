Рефакторинг разбивается на безопасные этапы:

Phase 0 — Baseline
Phase 1 — Observability
Phase 2 — Tests
Phase 3 — Contract stabilization
Phase 4 — Internal refactoring
Phase 5 — Performance optimization
Phase 6 — Cleanup

Каждый этап содержит:

    цель;

    затрагиваемые файлы;

    зависимости;

    риски;

    критерии входа;

    критерии завершения;

    план отката.
