Описание текущей архитектуры:

Компонент A
    ↓
Компонент B
    ↓
Компонент C

Для каждого компонента:

    ответственность;

    входы;

    выходы;

    состояние;

    потоки выполнения;

    внешние зависимости;

    ошибки и восстановление.

Важно описывать не желаемую архитектуру, а сначала фактически найденную.
